# IoT-core

## Поднятие Postgres
### 0. Необходимо

Докер и плагин композ, см. туториал для вашей системы

### 1. Открыть терминал в корне проекта

В IntelliJ: `Alt+F12`

### 2. Поднять базу

```bash
docker compose up -d
```

При первом запуске Docker скачает образ `postgres:16` и создаст том для данных. Флаг `-d` запускает контейнер в фоне.

### 3. Проверка

```bash
docker compose ps
```

В колонке статуса должно быть `running` (или `Up`).

### 4. Запуск приложения

При старте `Main` сам выполняет `schema.sql` и создаёт нужные типы и таблицы. Повторные запуски безопасны: что уже есть, то пропускается.

## По желанию: установка DBeaver для просмотра таблиц

Скачай [DBeaver Community](https://dbeaver.io), создай подключение **PostgreSQL** и впиши значения вручную (сам DBeaver файл `db.properties` не читает):

| Поле | Значение |
|---|---|
| Host | `localhost` |
| Port | `5432` |
| Database | `iot` |
| Username | `iot` |
| Password | `iot` |

Скрипты выполняются через `Alt+X`, один запрос под курсором через `Ctrl+Enter`.

## Полезные команды

| Команда | Что делает |
|---|---|
| `docker compose stop` | остановить, контейнер остаётся |
| `docker compose start` | запустить снова |
| `docker compose down` | остановить и удалить контейнер, данные в томе остаются |
| `docker compose down -v` | то же, но **вместе с данными** (чистая база с нуля) |
| `docker compose logs -f postgres` | следить за логами (выход: `Ctrl+C`) |
